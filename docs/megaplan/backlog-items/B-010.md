# B-010: Bias Inferrer

**Objective:** Annotate each news source with ideological bias inferred by LLM.

**Status:** done

**Notes:**
- `src/resenha/bias.py` created with `infer_source_bias()` and `annotate_news()`.
- `tests/test_bias.py` created with 4 tests.
- All 40 tests pass.
- Cache TTL: 30 days (bias doesn't change often).
- Returns "unknown" on LLM failure.

**Tasks:**
1. Create `src/resenha/bias.py`:
   - `infer_source_bias(source_name: str, gemini: GeminiClient)` → `str`:
     - Sends a one-sentence prompt: "What is the ideological bias of {source_name}? Respond in 10 words or less."
     - Caches result in SQLite `bias` table (indefinite TTL — bias doesn't change often).
     - Returns bias label string.
   - `annotate_news(news: list[NewsItem], gemini: GeminiClient)` → `dict[str, str]`:
     - For each unique source in news, calls `infer_source_bias`.
     - Returns mapping: source name → bias label.
2. Write `tests/test_bias.py`:
   - Mock GeminiClient, assert correct prompt contains source name.
   - Assert cache hit skips LLM call.
   - Assert all unique sources in news list are queried.

**Acceptance Criteria:**
- Each unique source gets exactly one LLM call (dedup + cache).
- Bias labels are cached indefinitely.
- Graceful on LLM failure: returns "unknown".
- All tests pass.
