# B-024: Email and Calendar Daily Agenda

**Objective:** Aggregate this week's Google Calendar events and relevant unread Gmail messages into a new `## Agenda da Semana` section in the briefing.

**Status:** done

**Domain Terms:**
- **Agenda:** a summary of upcoming calendar events and recent unread emails relevant to the user's day.
- **Relevant emails:** unread Gmail messages received in the last 24 hours, limited to the 5 most recent.
- **Week events:** calendar events from now through the next 7 days.

**Tasks:**
1. Update Google OAuth scopes:
   - The existing Google OAuth token likely has Sheets/Drive scopes only.
   - Re-authorize with Gmail and Calendar read-only scopes so Resenha can read Gmail and Calendar.
2. Create `src/resenha/agenda.py`:
   - `CalendarEvent` dataclass: `summary`, `start`, `end`, `location`, `description`.
   - `EmailSummary` dataclass: `sender`, `subject`, `received_at`.
   - `fetch_calendar_events(token_path: Path, max_results: int = 20) -> list[CalendarEvent]`:
      - Use `googleapiclient.discovery.build('calendar', 'v3', credentials=...)` with credentials from the configured token file.
     - Query primary calendar for events from `datetime.now(timezone.utc).isoformat()` through `now + 7 days`.
     - Parse `start.dateTime` or `start.date`.
   - `fetch_relevant_emails(token_path: Path, max_results: int = 5) -> list[EmailSummary]`:
     - Use Gmail API `users().messages().list(userId='me', q='is:unread newer_than:1d')`.
     - Fetch minimal headers (`From`, `Subject`, `Date`) for each message.
     - Return up to `max_results` most recent.
3. Update `src/resenha/assembler.py`:
   - Add `agenda: AgendaData` field to `BriefingContext` (or `None`).
   - Create `AgendaData` dataclass holding `events: list[CalendarEvent]` and `emails: list[EmailSummary]`.
4. Update `src/resenha/prompts.py`:
   - Add `## Agenda da Semana` section after portfolio and before macro.
   - Render events as `- [date/time] summary (location)`.
   - Render emails as `- [from] subject`.
   - If no events/emails, render "Nada relevante por enquanto."
5. Update `src/resenha/pipeline.py`:
   - After fetching macro and before fetching news, call agenda fetchers.
   - Wrap in `_try_step` with graceful degradation.
   - Pass agenda data to `assemble_briefing_data()`.
6. Write tests in `tests/test_agenda.py`:
   - Mock Gmail API and assert `fetch_relevant_emails` returns expected senders/subjects.
   - Mock Calendar API and assert `fetch_calendar_events` returns events within next 7 days.
   - Test graceful failure returns empty lists.
7. Update `tests/test_prompts.py`:
   - Assert prompt contains `## Agenda da Semana` when agenda data is present.
   - Assert event and email summaries appear in prompt.
8. Update `tests/test_pipeline.py`:
   - Mock agenda fetchers and assert they are called.

**Acceptance Criteria:**
- OAuth token has Gmail read-only and Calendar read-only scopes.
- This week's calendar events appear in the briefing prompt.
- Up to 5 recent unread emails appear in the briefing prompt.
- Agenda section degrades gracefully if APIs fail.
- All tests pass.
