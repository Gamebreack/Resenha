**Tasks:**
1. Create `src/resenha/scheduler.py`:
   - `ResenhaScheduler` class with `start()` and `stop()` methods.
   - Uses `asyncio.create_task` with a loop that checks time every 30 seconds.
   - Triggers pipeline via `run_pipeline()` coroutine (to be created — see task 3).
   - Schedule: Mon-Fri 7:00 BRT (pre-market), Mon-Fri 19:00 BRT (EOD), Sat 7:00 BRT (long-form).
   - Respects `Settings.premarket_hour` and `Settings.eod_hour` from config.
   - BRT = UTC-3. Use `datetime.now(timezone.utc)` and offset math — no `pytz` dependency.
   - Logs each trigger at INFO level: "Running {style} briefing".
   - Prevents duplicate runs within the same minute via a last-run timestamp.
2. Create `src/resenha/pipeline.py`:
   - `run_pipeline(style: str)` coroutine that orchestrates the full flow:
     - `get_prices()` → `get_macro()` → `get_news()` → `build_briefing_context()` → `generate_briefing()` → `generate_embeds()` → `run_bot()`
   - Returns the briefing text for logging.
   - Handles partial failures gracefully: if one fetcher fails, continue with remaining data (log WARNING).
3. Rewrite `src/resenha/__main__.py`:
   - CLI entry point using `argparse`: `python -m resenha [--schedule | --once STYLE]`
   - `--schedule`: starts `ResenhaScheduler` and runs until Ctrl+C.
   - `--once STYLE`: runs pipeline once with given style (pre-market, eod, long-form) and exits.
   - Loads `Settings` from env, passes to scheduler/pipeline.
4. Write tests in `tests/test_scheduler.py`:
   - Test `ResenhaScheduler` computes next run time correctly for each schedule slot.
   - Test duplicate prevention: second trigger within same minute is skipped.
   - Test `run_pipeline()` calls all fetchers in correct order (mock all dependencies).
5. Write tests in `tests/test_pipeline.py`:
   - Test partial failure: mock news fetcher to raise, verify pipeline still completes with prices+macro.
   - Test full pipeline returns briefing text.

**Acceptance Criteria:**
- `python -m resenha --schedule` starts scheduler and triggers at correct BRT times.
- `python -m resenha --once pre-market` runs full pipeline once and exits.
- Duplicate runs within the same minute are prevented.
- Partial fetcher failures don't crash the pipeline.
- All existing + new tests pass.
