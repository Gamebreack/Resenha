# B-029: Tornar dependências reprodutíveis com lockfile

**Objective:** Registrar as versões exatas das dependências do Resenha para tornar as instalações reproduzíveis.

**Status:** PENDING

## WHAT — Qual é o problema?

O `pyproject.toml` define dependências com versões mínimas, como `google-genai>=0.1.0`, mas não registra o conjunto exato de versões usado pelo projeto.

## WHY — Por que ele existe?

Uma nova instalação pode resolver versões diferentes das atuais. Uma atualização de dependência pode introduzir incompatibilidade ou mudança de comportamento sem nenhuma alteração no código do Resenha.

## HOW — Como solucionar?

1. Revisar o `uv.lock` gerado localmente.
2. Validar a instalação e a suíte de testes usando o lockfile.
3. Versionar o `uv.lock` no repositório.
4. Documentar o comando oficial de instalação reprodutível.

## Acceptance Criteria

- O `uv.lock` contém as dependências diretas e transitivas necessárias.
- A instalação a partir do lockfile é reproduzível.
- A suíte existente continua passando.
- O README documenta o fluxo oficial de instalação.
- A implementação é registrada em um commit separado.

## Non-goals

- Atualizar deliberadamente as versões das dependências.
- Alterar o código da aplicação.
- Conteinerizar o projeto.

## Discussão futura

Conteinerização com Docker foi sinalizada como uma possível evolução futura para simplificar instalação, execução e remoção do ambiente. Ela não faz parte deste item e deverá ser discutida separadamente.
