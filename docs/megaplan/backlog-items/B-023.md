# B-023: Briefing Memory

**Objective:** Persist the last generated briefing for each style and inject it into the next prompt so the model avoids repeating itself and can reference prior context.

**Status:** done

**Domain Terms:**
- **Briefing memory:** the text of the most recently generated briefing for a given style (`pre-market`, `eod`, `long-form`).
- **Style:** the briefing type passed to `run_pipeline` and `generate_briefing`.

**Tasks:**
1. Create `src/resenha/memory.py`:
   - `BriefingMemory(db_path: str | Path)` class wrapping a SQLite table `past_briefings`.
   - Schema: `id INTEGER PK AUTOINCREMENT, style TEXT NOT NULL, briefing_text TEXT NOT NULL, created_at TEXT DEFAULT (datetime('now'))`.
   - `save(style: str, text: str) -> None` — inserts a new row.
   - `get_last(style: str) -> str | None` — returns the most recent `briefing_text` for that style, or `None`.
   - `prune(style: str, keep: int = 1) -> None` — deletes older rows for the style, keeping only the latest (default 1).
2. Update `src/resenha/pipeline.py`:
   - After `generate_briefing()` succeeds, create a `BriefingMemory` and call `save(style, briefing_text)`.
3. Update `src/resenha/prompts.py`:
   - Extend `build_briefing_prompt()` to accept an optional `previous_briefing: str | None` parameter.
   - If provided, prepend a `## Resumo Anterior` section containing the previous briefing text (truncated to ~2000 tokens/characters if needed) before `## Portfólio`.
   - Add instruction: "Evite repetir informações já presentes no resumo anterior; destaque apenas o que é novo ou mudou."
4. Update `src/resenha/summary.py`:
   - `generate_briefing()` signature already accepts `context`, `gemini`, `style`, `feedback_text`. Add optional `previous_briefing: str | None = None` and pass it to `build_briefing_prompt()`.
5. Update `src/resenha/pipeline.py`:
   - Before generating the new briefing, call `memory.get_last(style)` and pass the result to `generate_briefing()`.
6. Write tests in `tests/test_memory.py`:
   - `test_save_and_get_last`: save two briefings for the same style, `get_last` returns the most recent.
   - `test_get_last_missing_style`: returns `None` when no prior briefing exists.
   - `test_prune_keeps_only_latest`: verify old rows are removed.
7. Update `tests/test_prompts.py`:
   - Assert that when `previous_briefing` is provided, the prompt contains `## Resumo Anterior` and the previous text.
   - Assert the "evite repetir" instruction is present.
8. Update `tests/test_pipeline.py`:
   - Assert pipeline calls `BriefingMemory.save()` with the generated text.
   - Assert pipeline passes the previous briefing to `generate_briefing()` when memory exists.

**Acceptance Criteria:**
- Last briefing per style is persisted in SQLite.
- Prompt includes previous briefing when available.
- Model receives instruction to avoid repetition.
- Memory is fetched before generation and saved after generation.
- All tests pass.
