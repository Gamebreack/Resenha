# B-016: Feedback Weighting

**Objective:** Compute per-asset and per-source engagement scores from reaction data, providing input for adaptive briefing.

**Status:** done

**Notes:**
- `src/resenha/feedback.py` created: scoring, normalization, merge functions.
- 90 tests pass (76 + 14 new).

**Tasks:**
1. Create `src/resenha/feedback.py`:
   - `REACTION_WEIGHTS = {"up": 1, "down": -1, "love": 2, "fire": 1}` as a module-level dict.
   - `compute_asset_scores(stats: dict[str, dict[str, int]], weights: dict | None = None) -> dict[str, float]`:
     - Input: `ReactionTracker.get_stats()` output: `{ticker: {"up": N, "down": M, ...}}`.
     - For each ticker, compute `score = sum(count * weight)` across all reactions.
     - Return `{ticker: score}` sorted by score descending. Skip `__unknown__`.
   - `compute_source_scores(stats, weights=None) -> dict[str, float]`:
     - Same logic, delegates to `compute_asset_scores` for now (sources = tickers). Will be refined as news sources are tracked.
   - `normalize_scores(scores: dict[str, float]) -> dict[str, float]`:
     - Scale scores to 0.0–1.0 range using min-max normalization.
     - If all scores identical, return all 0.5.
   - `merge_feedback_into_context(asset_scores: dict, source_scores: dict) -> str`:
     - Generate a compact text block to inject into the briefing prompt (used by B-017).
     - Format: "Engajamento recente: ITUB4 ↑ (3.2), BBDC4 ↓ (-1.5), ..."
2. Write tests in `tests/test_feedback.py`:
   - `test_compute_asset_scores_basic`: given up=2, down=1 → score=1.0.
   - `test_compute_asset_scores_with_love_and_fire`: love and fire weighted correctly.
   - `test_compute_asset_scores_skips_unknown`: `__unknown__` excluded.
   - `test_normalize_scores_range`: all values between 0.0 and 1.0.
   - `test_normalize_scores_identical`: returns all 0.5.
   - `test_merge_feedback_into_context_format`: output contains ticker names and scores.
   - `test_custom_weights`: passing custom weight dict overrides defaults.

**Acceptance Criteria:**
- Scores computed correctly per reaction weight.
- `__unknown__` tickers excluded.
- Normalization produces values in [0, 1].
- Merge output is a compact, parseable string.
- All existing + new tests pass.
