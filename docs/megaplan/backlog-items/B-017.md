# B-017: Adaptive Briefing

**Objective:** Inject engagement feedback into the briefing prompt so Gemini adjusts depth and tone based on what users react to.

**Status:** done

**Notes:**
- `src/resenha/adaptive.py` created: build_adaptive_context(), inject_feedback().
- `src/resenha/summary.py` modified: generate_briefing() accepts feedback_text.
- `src/resenha/pipeline.py` modified: injects reaction feedback into briefing prompt.
- `tests/test_adaptive.py` created: 8 tests.
- All 98 tests pass.

**Tasks:**
1. Create `src/resenha/adaptive.py`:
   - `build_adaptive_context(tracker: ReactionTracker, days: int = 7) -> str`:
     - Calls `tracker.get_stats(days)`.
     - Passes to `compute_asset_scores()` and `normalize_scores()`.
     - Returns `merge_feedback_into_context(asset_scores)` as string.
     - If no reaction data (empty stats), returns `""` (empty string).
   - `inject_feedback(prompt: str, feedback_text: str) -> str`:
     - Inserts `feedback_text` into the prompt before the first `## ` section header.
     - If no `## ` header found, appends to end.
     - Wraps feedback in a `### 📊 Engajamento` section.
     - If `feedback_text` is empty, returns `prompt` unchanged.
2. Update `src/resenha/summary.py`:
   - Modify `generate_briefing()` to accept an optional `feedback_text: str = ""` parameter.
   - After `build_briefing_prompt()`, call `inject_feedback(prompt, feedback_text)`.
3. Update `src/resenha/pipeline.py`:
   - After `generate_embeds()`, create a `ReactionTracker` and call `build_adaptive_context()`.
   - Pass the result to `generate_briefing()` via the new `feedback_text` parameter.
   - Order: generate briefing WITH feedback → generate embeds → deliver.
   - Wait — the current order is: generate_briefing → generate_embeds → run_bot.
   - We need feedback to influence the briefing text, so feedback must be computed BEFORE generate_briefing.
   - Move the ReactionTracker creation to before step 6 (generate briefing), get feedback, pass to generate_briefing.
4. Write tests in `tests/test_adaptive.py`:
   - `test_build_adaptive_context_with_data`: mock tracker returning stats with reactions, verify output contains "Engajamento recente".
   - `test_build_adaptive_context_empty`: mock tracker returning {}, verify returns "".
   - `test_inject_feedback_inserts_before_headers`: prompt with `## ITUB4`, feedback injected before it.
   - `test_inject_feedback_empty_text`: returns prompt unchanged.
   - `test_generate_briefing_passes_feedback`: mock build_briefing_prompt and inject_feedback, verify both called.

**Acceptance Criteria:**
- `build_adaptive_context()` returns empty string when no reaction data.
- `inject_feedback()` places feedback before `##` headers.
- Pipeline passes feedback to `generate_briefing()`.
- All existing + new tests pass.
